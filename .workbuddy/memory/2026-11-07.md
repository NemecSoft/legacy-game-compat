- 用户给的 0x0058CA2F：objdump 实证包内 Heroes3.exe 该地址正是 `div DWORD PTR ds:0x821754`（整数除法），除数是 .bss 全局变量、全代码仅此一处绝对引用；0x58C9xx 附近是一段把全局配置值（0x821748 / 760 / 770 / 774 / 778）经 fild / fdivr / call 0x7623c8 换算成时序的标定例程，0x7623c8 = __ftol。故「配置值缺失 → 除数保持 0 → 除零」逻辑成立，但不是「直接拿 AppPath 做除法」。
