# 绝命时刻：五星之光 —— 适配过程分析

- 游戏目录：`D:\YunGame\Command.and.Conquer\Command.and.Conquer.FiveStar`
- 类型：Command & Conquer: Generals – Zero Hour 的国产模组（Huixian 独立安装版 V1.3）
- 原启动方式：`go.bat` → `初始注册程序130.exe`（算号/注册）→
  `五星独立版专用画质管理器130.exe`（画质）→ 玩家在画质管理器里点「运行游戏」
- 游戏入口：`generals.exe`（与 `FiveStarHX.exe` 同 hash），实际引擎进程是 `Game.dat`

## 1. 原生运行与兼容层

- 原生 `generals.exe`：能拉起 `Game.dat`，但出现标题为 `DirectX ?` 的空错误窗，
  随后退出；`game.dat_d3d9.log` 没有机会产生。判定原生 D3D8 在本机不可用。
- 加入 DXVK 2.5.3（x86 `d3d8.dll` + `d3d9.dll` + `dxvk.conf`）后：
  - 第一次用 `1280×800` 全屏：DXVK 日志 `D3D9: EnterFullscreenMode: Failed to change display mode`，
    游戏报 DirectX 错误；
  - 改为 `Resolution = 1920 1080` 后正常进入主菜单，DXVK HUD 正常显示。
- 结论：DXVK 2.5.3 可用；分辨率必须是当前显示器支持的 fullscreen 模式（本机 1920×1080）。
  启动器因此不提供 1280×800，改用 1920×1080 / 1600×900 / 1280×720 / 1024×768 / 800×600。

## 2. REA 分析：算号器 `初始注册程序130.exe`

- 文件：PE32 原生程序，MFC（字符串含 `FK3DRegApp`、`CDialog`），
  sha256 `7004395ac8e1a01fc9f4552c7a6d39ed812ad173eb9af12c5fd9d4568ba8a5a9`。
- REA/Ghidra 12.1.3 打开成功（.text/.rdata/.data/.rsrc）；ASCII 字符串直接给出写入逻辑：
  `SOFTWARE`、`Command and ConquerGeneralsFiveStar130`、`EA Games`、`Electronic Arts`、
  `Command and Conquer Generals Five Star Data`、`Import.reg`、`InstallPath`、`chinese`、
  `Language`、`UserDataLeafName`、`\ergc`。
- 实际注册表（32 位视图，即 `WOW6432Node`）：
  - `HKLM\SOFTWARE\Electronic Arts\EA Games\Command and ConquerGeneralsFiveStar130`
  - `InstallPath` = 游戏目录
  - `Language` = `chinese`
  - `MapPackVersion` = `0x10000`
  - `Version` = `0x20000`
  - `Proxy` = 空字符串
  - `UserDataLeafName` = `Command and Conquer Generals Five Star Data`
  - 子键 `ergc` 默认值 = 20 位数字序列号
- 动态验证：
  - 原算号器每次运行生成新的 20 位序列号（采样 6 次，都是 20 位数字，前缀/后缀无固定关系）；
  - 把 `ergc` 改成任意 20 位数字 `12345678901234567890` 后游戏仍能进主菜单，
    说明游戏只要求 20 位数字注册码，不校验算法；
  - 因此启动器重实现为：缺失/无效时生成随机 20 位数字；`/newserial` 或「算号并注册」
    强制重新生成。保留已有合法序列号，不每次启动改号。
- 注册表写入需要管理员；启动器直接写失败时用自身 `/fixreg` 走 UAC 再写。

## 3. REA 分析：画质管理器 `五星独立版专用画质管理器130.exe`

- 文件：PE32 原生程序，sha256
  `2837f69e62e7742b31018d0dfe8f992aa2bdd0017f6c821aae1f210d77f4faa1`。
- REA/Ghidra 12.1.3 打开成功；字符串直接给出它写 `Options.ini`：
  `.\GraphicSetter.ini`、`ResoFont`、`.\Data\Chinese\Language.ini`、
  `.\Options.ini`、AntiAliasing / Gamma / TextureReduction / MaxParticleCount /
  ShowSoftWaterEdge / BuildingOcclusion / ExtraAnimations / DynamicLOD / ShowTrees /
  HeatEffects / UseCloudMap / UseLightMap / UseShadowDecals / UseShadowVolumes /
  Resolution / CampaignDifficulty / IdealStaticGameLOD / StaticGameLOD 等。
- Options.ini 路径：
  `%USERPROFILE%\Documents\Command and Conquer Generals Five Star Data\Options.ini`。
- 原管理器还处理 `DX9.ini`、`Terrain.ini`、`GraphicSrc\!NoWater*.big` / `!NoBloom*.big`
  和字体；本轮只重实现影响实际画面的 Options.ini 项，BIG/字体开关不自动改，
  玩家仍可在游戏「选项」里调节。
- 重实现：启动器 6 个画面方案 + 5 档亮度，写以下键（保留 Options.ini 里其它设置）：
  `Resolution`、`Gamma`、`UseFPSLimit=no`、`FPSLimit=60`、
  `AntiAliasing`、`TextureReduction`、`MaxParticleCount`、`ShowSoftWaterEdge`、
  `BuildingOcclusion`、`ExtraAnimations`、`DynamicLOD`、`ShowTrees`、`HeatEffects`、
  `UseCloudMap`、`UseLightMap`、`UseShadowDecals`、`UseShadowVolumes`、
  `StaticGameLOD=Custom`、`IdealStaticGameLOD`。
- 实测：原版 30 FPS 上限；加入 `UseFPSLimit=no` / `FPSLimit=60` 后，
  1920×1080 高画质主菜单稳定 `FPS: 59.0`（`evidence/fivestar-60fps.png`）。

## 4. 启动器（`game_starter.exe`）

- 三栏中国红 GUI：左栏游戏介绍；中栏画面方案 / 亮度 / 启动 / 算号并注册 / 日志 / 退出；
  右栏进游戏说明、C&C 操作键帽、提示。
- 启动前自动：
  1. 检查 DXVK 层（`d3d8.dll` + `d3d9.dll` + `dxvk.conf`，缺失从 `_dxvk` 复制）；
  2. 检查/写入注册表（保留已有合法 20 位序列号；缺失才生成）；
  3. 把所选画面方案和亮度写入 `Options.ini`，同时解除 30 FPS 上限；
  4. 启动 `generals.exe`，等待实际 `Game.dat` 进程，游戏退出后回传它的退出码。
- 命令行：
  - `game_starter.exe /go`：默认 1920×1080 高画质、亮度 30、零交互；
  - `/preset 1-6 /gamma 1-5 /go`：指定画面方案和亮度（给平台/bat 用）；
  - `/fixreg`：只写注册表；`/fixreg /newserial`：重新算号并注册。
- 平台托管：`Game.dat` 是 `generals.exe` 的子进程、启动器的孙进程；启动器全程陪跑，
  关窗隐藏不杀游戏，游戏退出后原样回传 `Game.dat` 退出码（与 DFBHD/未来战士同类限制）。
