# 破坏者 The Saboteur 适配过程

## 目录与启动链

- 游戏：`D:\YunGame\2023\TheSaboteur`，Pandemic 2009 简体中文硬盘版，主程序 `Saboteur.exe`。
- 启动器：GUI `game_starter.exe`（默认）与菜单版 `game_starter.bat` 平级，选项/顺序/默认值一致。
- 游戏是启动器的**直接子进程**；启动器陪跑，游戏退出后原样回传退出码，关启动器窗口不杀游戏。
- 不加分辨率/窗口参数，不改游戏自身设置；分辨率由启动器写 `config.ini`。

## 兼容层选择（为什么是 DXVK 2.5.3，不是 dgVoodoo2）

- 现场原有 ReShade 4.9.1 的 `d3d9.dll`，`d3d9.log` 报
  `IDirect3D9::CreateDevice failed with error code D3DERR_NOTAVAILABLE`。
- dgVoodoo2 本机实测：D3D11 后端失败，D3D12 后端直接退出；
  **本机（RX 580 / Win11）dgVoodoo2 的 D3D11/D3D12 后端不可用**，所以不选它。
- DXVK 2.3.1 → 白屏（日志没有 `ResetSwapChain`，卡在首次 Present 前）；
  **DXVK 2.5.3 → 正常**，HUD `DXVK v2.5.3 / D3D9 / 59.4 FPS`。
- 生效文件：`d3d9.dll`（DXVK 2.5.3）；`_dxvk\` 留底 `d3d9.dll` + `dxvk.conf`
  （HUD=`fps`，左上角只显示帧数；历史取证截图带 version/api）。
  原 ReShade 改名 `d3d9.dll.reshade-bak`，旧 DXVK 2.3.1 改名 `d3d9.dll.dxvk231-bak`，均保留可回滚。

## 分辨率（写游戏官方配置）

- 路径：`我的文档\My Games\The Saboteur™\SaveGames\config.ini`（制表符分隔）。
- 启动器只改 `ScreenWidth` / `ScreenHeight` 两行，`RefreshRate` / `VSync` 和其它设置不动。
- 5 档：1920×1080（默认） / 1600×900 / 1280×720 / 1024×768 / 800×600。
- GUI 下拉框和 `game_starter.exe /setres N` 走同一个落地函数；`game_starter.bat` 菜单 1-5 调 `/setres`。
- 实测（2026-11-02）：`/setres 3` → `1280×720`、退出码 0；`/setres 1` → `1920×1080`、退出码 0；
  已恢复到 1920×1080。`config.ini` 不存在时启动器提示先运行一次 `VideoSetup.exe` 或进一次游戏，
  不凭空创建整份配置。

## 启动器

- GUI `game_starter.exe`（900×620 三栏、规范红渐变、正常 TextRenderer ClearType）：
  - 中栏：画面/分辨率下拉框、启动游戏、打开运行日志、退出。
  - 右栏：进游戏说明、操作说明（键帽：WASD、鼠标、空格、E、Q、M、F、V、Shift、Ctrl）、提示；可滚轮。
  - 左栏：游戏介绍 + 玩不了或报错；状态只在左下角出现一次。
- 菜单版 `game_starter.bat`：1-5 分辨率 / 6 日志 / 7 退出，`/go` 跳过菜单用默认 1920×1080。
- 构建：`Games\TheSaboteur\build.ps1` → `out\game_starter.exe`（32.5 KB，≤60 KB）；
  构建时从 `Saboteur.exe` 抽图标生成 `out\game_starter.ico` 并 `-win32icon` 嵌入，
  文件图标与游戏图标一致（SHA-256 实测相同）；`.ico` 不进游戏目录。
- bat 源码 UTF-8，部署时转 GBK+CRLF；游戏目录无 `.cs` / `.ps1`。

## 一键应用 / 一键撤回（交付包）

- 位置：`Games\TheSaboteur\release\`，只有两个入口 `一键应用.bat`、`一键撤回.bat` + `payload\`。
- payload：`game_starter.exe`、`game_starter.bat`、`launcher.ini`、`兼容修复.bat`、`恢复原版.bat`、
  `d3d9.dll`（DXVK 2.5.3）、`dxvk.conf`、`_dxvk\d3d9.dll`、`_dxvk\dxvk.conf`、`_tools\nircmd\ircmdc.exe`。
- 应用：拖入或输入目标目录，校验 `Saboteur.exe`；目标同名文件先备份到
  `_legacy_compat_backup\TheSaboteur\`，再复制；写 `交付记录.txt`。
- 撤回：按备份恢复被替换的原文件；没有原备份的交付文件只在和 payload 完全一致时删除；
  玩家改过的文件保留并记录“跳过”；删除 `运行日志.txt`、`Saboteur_d3d9.log`、`Saboteur.dxvk-cache`；
  `ReShade.ini`、`ReShadePreset.ini`、`reshade-shaders\`、游戏资源和存档不动。
- 不能完全恢复的项写进记录：外部 `我的文档\...\config.ini`（启动器启动时写分辨率，撤回不自动还原）、
  被修改过的目标文件、运行产物。备份目录和记录撤回后保留。
- 源脚本：`src\一键应用.bat` / `src\一键撤回.bat`（UTF-8+CRLF）；`build-release.ps1` 转 GBK+CRLF
  并组装 payload/manifest；`src\dxvk.conf` 已回存，`build.ps1` 会部署它。
- 测试（`tools\test-delivery.ps1`）：用带原 ReShade `d3d9.dll` 的假目标跑应用→撤回，全部 PASS；
  再测“玩家修改 d3d9.dll / game_starter.bat 后撤回”会保留修改并记录跳过，PASS。
  记录证据：`evidence\delivery-apply-record.txt`、`delivery-revert-record.txt`、
  `delivery-modified-record.txt`。
