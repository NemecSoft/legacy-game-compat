# 命令与征服：红色警戒1复刻版-网吧联机版（CC1-RedAlert）适配过程分析

游戏目录：`D:\YunGame\F\CC1-RedAlert`（2026-11-20 点名交付）。

## 游戏本体与启动契约（REA 取证）

- 本体是 **OpenRA playtest-20261026 红警1简体中文便携整合版**：.NET 10 自包含引擎
  （coreclr / hostfxr / hostpolicy 随包），SDL2 + OpenGL/ANGLE 渲染。
- 自带 `启动游戏.exe` 用 ilspycmd 反编译取证（`evidence\启动游戏.decompiled.cs`）：
  真游戏 = `Engine\RedAlert.exe`；`WorkingDirectory = Engine`；
  参数 = `Game.Mod=ra ` + 引号包裹的 `Engine.LaunchPath=<游戏目录全路径>`
  （引号按 MSVCRT 反斜杠计数规则转义）。启动器逐字复刻这条契约。
- 不复刻自带版的 XDGAME 标题改写与 TitleProtection：那是对游戏窗口的干预，违反规则 44。
- 本机无硬件 OpenGL（只有 GL 1.1 / GDI Generic），OpenRA 的 ANGLE 走 D3D11 能否真跑
  **未验证**——真启动单次实测带 `-AllowGameLaunch` 门禁，需要时再做，不反复拉起。

## 启动器功能（game_starter.exe，59KB）

- **联机显示名自动按机器名**（用户点名）：每次启动前无条件把 `Environment.MachineName`
  写进 `Engine\Support\settings.yaml` 的 `Player: Name:` 行。只改这一行、其余字节不碰；
  保留原换行（LF 或 CRLF）与缩进；值含特殊字符时转双引号。读→比较→相同不动（幂等）。
  缺文件建默认、缺 Name 行在节头后插、缺 Player 节末尾补。GUI 与 `--go` 同一条路径。
- 文件自检 13 项（Engine 核心 + mods\ra\mod.yaml + Support）、环境读数带断言、
  WER 崩溃报告解析（中英文 Sig 名都认）、`--go` / `--hideparent` / `--selftest` / `--wer` / `--readings`。
- 平台托管契约：游戏是直接子进程、陪跑期间主窗口保持可见、退出码原样回传、
  玩家关窗转托盘不杀游戏、游戏退出后窗口自动关闭。
- 皮革三栏 900×620、CenterScreen 一步算完、统一仓库图标、页脚 YunGame（XOR + SHA-256 自校验）。

## 右栏一屏改造（2026-11-20 用户定案）

用户原话：「这个右侧说明一屏就行，不要单独开窗口了。战神的操作说明是没办法，太多了。」

- 删 `CheatSheetForm` 独立窗口、六卡片数据与绘制、`rcCheats` 按钮、焦点序里的 5 号位，
  共 326 行；完整说明压进主窗口右栏 9 行（同类动作合并一行、一帽一键、说明压单行）。
- 高度预算实测：内容高 440px ≤ 视口 450px（`LogRightTableFit` 自证行「需要滚动=False」）。
  压缩手法：行内键帽与说明间距 1px、行与行 2px（行内紧、行间松），标题下 4px。
- 中栏改**顶对齐**（`y = colCenter.Y + S(12)`）：原垂直居中配方在内容稀疏时顶部留约 150px
  空洞，与规则 20 冲突；改后三栏标题同一水平线。滚动条保留作兜底（默认不出现）。
- 焦点序改 {0,2,3}（busy {2,3}）：启动游戏 → 打开运行日志 → 退出。
