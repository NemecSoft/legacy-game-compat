幽灵行动：未来战士 修改器说明

一、为什么修改器不能用

附件里的 LinGon v1.8 修改器（DX9/DX11 两个版本）带 Themida/WinLicense 壳，
启动时会做“反虚拟机”检测。本机 Windows 11 开启了基于虚拟化的安全（VBS/内存完整性，
HypervisorPresent=True），修改器会误报：

  Sorry, this application cannot run under a Virtual Machine.

这不是游戏版本不对，也不是 DX9/DX11 选错；两个修改器都会这样。

另外，原来的 go.bat 会给游戏写 WINXPSP3 + RUNASADMIN（XP 兼容性 + 管理员运行）。
游戏一旦以管理员权限运行，普通权限的修改器也无法注入。本机已把这两项移除，
启动器也不会再写；不要再用 go.bat。

二、已做的处理

- 移除 Future Soldier DX9/DX11 的 XP 兼容性/RUNASADMIN 注册表项（已备份）。
- 启动器直接使用 DX11 原生渲染，不加载 DXVK，不写兼容性。
- 启动器日志会记录启动链和退出码。

三、可选方案

1. 换一个没有反虚拟机壳的修改器，或用 Cheat Engine 表；这是最安全的办法。
2. 如果愿意做系统级更改：关闭“内存完整性/VBS”或 Hyper-V 后重启，再试原修改器。
   本仓库不自动改系统，也不建议为了一个修改器长期关闭安全功能。
3. 游戏和修改器都用管理员权限启动（只解决注入权限，不能绕过 Themida 的反虚拟机检测）。

四、结论

修改器不能用的根因是第三方修改器的反虚拟机保护，不是游戏本身；
游戏 DX11 已可正常启动。修改器问题已在启动器提示和本文件中记录。
