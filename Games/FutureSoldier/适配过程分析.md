## go.bat 的 XP 兼容性（已移除）

`go.bat` 会向 `HKCU\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers`
写入两个值：

- `Future Soldier DX11.exe` = `~ DWM8And16BitMitigation WINXPSP3 RUNASADMIN`
- `Future Soldier DX9.exe` = `~ DWM8And16BitMitigation WINXPSP3 RUNASADMIN`

这会让游戏以管理员权限运行，普通权限的修改器无法注入；XP 兼容层本身也不适合 Win11。
2026-11-02 已备份并只删除这两项：

- 备份：`backup\AppCompat-Layers-FutureSoldier.reg`、`backup\AppCompat-Layers-before.txt`；
  为便于查看，另存 `evidence\AppCompat-Layers-FutureSoldier.reg`、`evidence\AppCompat-Layers-before.txt`
- `tmp.reg` 已移到 `backup\tmp.reg.go-bat.before`
- `go.bat` 未改；启动器**不调用** go.bat，也不写任何兼容性项。
- `兼容修复.bat` 可重复执行同样的清理（导出 Layers 备份到
  `_legacy_compat_backup\FutureSoldier\`，只删这两个 exe 的值，并写记录）。

## 兼容层选择

- **DX11 原生可玩**：移除 XP 兼容性后直接启动 `Future Soldier DX11.exe`，
  在 RX 580 / Win11 上正常进游戏，1920×1080，无需 DXVK。
- 不使用 dgVoodoo2；不安装/替换任何渲染 DLL。
- 游戏按 `init.exe` → `Future Soldier.exe "Future Soldier DX11.exe"` 的原始链启动；
  `init.exe` 退出码 10 是正常的（只是初始化配置，不阻塞）。
- 启动器不加分辨率/窗口参数，不改 `default.cfg`；画质/分辨率在游戏内设置。

## 启动器

- GUI `game_starter.exe`（33 KB，已嵌入 `Future Soldier DX11.exe` 图标）：
  - 中栏：启动游戏 / 打开运行日志 / 退出；右栏进游戏说明、键帽、提示；左栏介绍/报错。
  - 启动链：`init.exe` → `Future Soldier.exe "Future Soldier DX11.exe"`。
  - 游戏实际进程是 `Future Soldier DX11.exe`；启动器会等待真正的游戏进程并取它的退出码，
    不是只拿包装器的 0。包装器是启动器的直接子进程，实际游戏是孙进程（游戏自身分层，
    和 DFBHD 外挂启动类似）。
  - 启动器陪跑到游戏退出并原样回传退出码；不置顶；关启动器窗口不杀游戏。
- 控制台 `game_starter.bat`：菜单 1 启动 / 2 日志 / 3 退出，`/go` 零交互；与 GUI 同链。
- `兼容修复.bat`：清理 XP 兼容性/RUNASADMIN（带备份和记录）。
- `修改器说明.txt`：给玩家的修改器限制说明。

## 修改器为什么不能用

附件 LinGon v1.8 修改器的 DX9/DX11 两个版本都是 **Themida/WinLicense** 加壳，
带反虚拟机检测。本机 Win11 开启了 VBS/内存完整性（`HypervisorPresent=True`，
`VirtualizationBasedSecurityStatus=2`），修改器启动即弹：

`Sorry, this application cannot run under a Virtual Machine.`

点确定后退出。PE 节区为 `.VCrypt0` / `.VCrypt1`，导入 `MSVBVM60.dll` /
`MessageBoxA`，明文里没有该字符串，检测在壳内。两个修改器表现相同；
不是游戏版本、DX9/DX11 选错，也不是启动器参数问题。

另外，原 go.bat 的 `RUNASADMIN` 会让游戏提升权限，普通修改器即使绕过反虚拟机检测
也无法注入；该兼容性项已移除。修改器仍会被 Themida 拦住，这是第三方保护与
Win11 虚拟化安全特性的冲突。没有在无人值守时关闭 VBS/Hyper-V，也没有脱壳/修改
第三方修改器（系统级更改需要重启，且违反本项目“不改系统”的约束）。

可选替代：换无壳修改器 / Cheat Engine 表；或用户自行关闭内存完整性/VBS 后重启再试。
详见 `evidence\trainer-vm-error.txt` 和游戏目录 `修改器说明.txt`。

## 一键应用 / 一键撤回（交付包）

- 位置：`Games\FutureSoldier\release\`，入口 `一键应用.bat`、`一键撤回.bat` + `payload\`。
- payload：`game_starter.exe`、`game_starter.bat`、`launcher.ini`、`兼容修复.bat`、
  `修改器说明.txt`、`_tools\nircmd\ircmdc.exe`；没有 DLL/兼容层文件。
- 应用：拖入或输入目标目录，校验 `Future Soldier DX11.exe`；同名文件先备份到
  `_legacy_compat_backup\FutureSoldier\`，复制交付文件，然后调用 `兼容修复.bat /quiet`
  清理目标的 XP 兼容性/RUNASADMIN；写 `交付记录.txt` 和 `兼容修复记录.txt`。
- 撤回：恢复被替换的文件；未被修改的交付文件删除；玩家改过的文件保留并记录“跳过”；
  删除 `运行日志.txt`；不碰 `Future Soldier DX11.exe`、存档、我的文档 `default.cfg`。
- 不能完全恢复的项已记录：我文档 `default.cfg` 的画质/分辨率、被玩家改过的目标文件、
  XP 兼容性/RUNASADMIN（不自动恢复，备份在 `_legacy_compat_backup`）。
- 源脚本：`src\一键应用.bat` / `src\一键撤回.bat`；`build-release.ps1` 负责转 GBK+CRLF
  并组装 payload/manifest。测试（`tools\test-delivery.ps1`）用假目标验证应用/撤回、
  XP 兼容性清除、玩家改文件后跳过，全部 PASS；记录见 `evidence\delivery-*.txt`。
