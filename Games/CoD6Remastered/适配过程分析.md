# 使命召唤6 现代战争2 重制版（CoD6 Remastered / MW2CR）适配过程分析

## 1. 游戏基本情况

- 目录：`D:\YunGame\CoD\CoD6.Remastered`
- 主程序：`MW2CR.exe`（真正进游戏的程序）、`MW2 Campaign Remastered Launcher.exe`（离线安装/启动器界面）
- 平台：**暴雪战网版离线整合版**（内部代号 lazarus）。证据：`.build.info` / `.product.db` 是战网格式，带 `tpr/lazr`、`blizzard.com` CDN；`data_steam` 是个 zip 包。机器上没装战网客户端。
- 需求：原版是英文，要能切换简体中文 / 繁体中文，做一个 GUI 启动器，直接启动 `MW2CR.exe`（不走 Launcher.exe）。

## 2. 语言机制怎么摸清的（关键）

**两处独立开关，都要写：**

1. **注册表**（游戏本体读）：
   `HKCU\Software\Blizzard Entertainment\Battle.net\Launch Options\LAZR` 下 `LOCALE` 字符串：
   - 简体 = `zhCN`，繁体 = `zhTW`，英文 = `enUS`
   - 这是社区通行方案（3DM 论坛《使命召唤6重制版 简/繁/英语言注册表转换》帖，https://bbs.3dmgame.com/thread-6041542-1-1.html）。原始状态：这个键在机器上**不存在**。
2. **`Launcher.db`**（离线安装器/部分版本读）：游戏目录里 4 字节纯文本，原始值 `enUS`。我把它改成 `zhTW` 后，Launcher.exe 的窗口标题立刻变成繁体《決勝時刻®：現代戰爭2》戰役重製版啟動程式——**证明这个文件控制安装器界面语言**。

**反证/排除：**
- `players2\default\config.cfg` 全是哈希键（`seta 0xXXXX "值"`），没有明文语言项，不动它。
- `CoD4.Remastered\4、简体中文化.BAT` 那套是替换 `players2\default\language` 文件，属于 CoD4 的机制，跟重制版无关，不混用。
- 网上那些"战网设置里改语言""抢在战网覆盖注册表前跑 bat"都是给**装了战网客户端**的正版用的，离线版用不上。
- 注册表 `reg.exe` 在本机被安全策略（Program Blacklist）拦，读写改用 PowerShell 的 `Get-ItemProperty` / `Set-ItemProperty`（只读+定向写游戏专用键，不碰系统其它地方）。

**语言包到底有没有简体：** 一开始看 `.build.info` / `.product.db` 的语言 Tags 只有 zhTW 没有 zhCN，怀疑简体包没装。但实测推翻了这个担心——设 `zhCN` 后游戏本体弹出的第一个对话框就是简体中文「是否在安全模式下运行？」（用窗口标题抓到的客观证据），说明**简体包在游戏文件里是有的，注册表 zhCN 生效**。

> 结论：社区方案成立。启动时把注册表 `LOCALE` 设为 zhCN，游戏就是简体。

## 3. 交付内容

**启动器 `game_starter.exe`**（37KB，单文件，皮革主题三栏布局，仓库统一图标 + SHA-256 自校验）：
- 规范三栏 900×620：左栏游戏简介 / 中栏操作区 / 右栏键帽操作说明（前后左右 WASD、跳跃、奔跑、蹲下、换弹、开火、瞄准、切换武器、暂停菜单）。
- 中栏是**自绘语言下拉框**（默认简体中文，上方紧贴一行「本下拉框的作用是：选好游戏语言，再点『启动游戏』。」），下拉菜单三项：简体中文 / 繁體中文 / English 英文；键盘 Tab 聚焦、上下键换档、Enter 展开。
- **先选语言、再点「启动游戏」**才应用并启动 `MW2CR.exe`——不是点语言就直接进游戏。
- 点启动时**同时写注册表 LOCALE 和 Launcher.db**，双保险，不管游戏本体还是安装器读哪个都对。
- 启动方式：`UseShellExecute=false`，游戏是启动器的直接子进程；游戏运行期间启动器缩到托盘陪跑；游戏退出后启动器跟着退出并原样回传退出码（平台靠 `0xC0000xxx` 判崩溃）。
- 游戏中关窗 = 隐藏到托盘，不杀游戏；双击托盘图标唤回。
- 零交互入口：`game_starter.exe /go /zhcn`（或 `/zhtw` / `/enus`），平台/快捷方式可直接用。
- 有「打开运行日志」按钮，技术细节只进 `运行日志.txt`，界面只说人话。
- 窗口 `CenterScreen` 居中。

**其它文件：**
- `game_starter.sha256`：exe 自校验清单。
- `使用说明.txt`：玩家看的大白话说明。
- `恢复英文.bat`：回滚——删掉启动器写的注册表 LOCALE 键 + 把 Launcher.db 写回 enUS。

**工作区（可复现）：**
- `Games\CoD6Remastered\src\Launcher.cs`：启动器源码。
- `Games\CoD6Remastered\build.ps1`：一键编译+部署+哈希+部署说明文件。
- `Games\CoD6Remastered\backup\Launcher.db.enUS.20261111`：**真正的原版** Launcher.db（4 字节 enUS）。
- `Games\CoD6Remastered\backup\Launcher.db.原版`：build.ps1 首次运行时留的底（注意：那时已是我改过的 zhTW，回滚请用上面那个 enUS 的）。
- 界面实测证据（PrintWindow 抓窗口自身，不截全屏）：`Games\CoD6Remastered\evidence\cod6-launcher-三栏.png`、`cod6-launcher-下拉展开.png`（键盘展开下拉、✓ 跟随选择、菜单不截断）。

## 5. 回滚

- **临时换语言**：重开启动器，中栏下拉框选另一种，再点「启动游戏」；或 `/go /zhcn`、`/go /zhtw`。
- **完全恢复原版英文**：游戏目录点 `恢复英文.bat`（删注册表 LOCALE 键 + Launcher.db 还原 enUS）。
- **彻底删除本交付**：删掉 `game_starter.exe` / `game_starter.sha256` / `使用说明.txt` / `恢复英文.bat` / `运行日志.txt` 即可；游戏本体和存档不受影响。

## 6. 局限与实话

- 游戏本体窗口标题恒为英文 `Call of Duty®: Modern Warfare® 2 Campaign Remastered`（产品名写死），**不能用标题判断界面语言**——要看游戏内弹窗/菜单（已用简体弹窗证实）。全屏 D3D 独占模式下截图工具抓不到游戏画面，属工具限制。
- 语音语言与界面文字可能分开；本启动器切的是界面/文字语言（注册表 LOCALE），中文语音是否可用取决于游戏文件里的语音包，本次未单独验证语音。
- 写注册表是当前用户（HKCU）下一个游戏专用键，不动系统、不动别的游戏，可一键删除回滚。这是本项目"不碰系统"铁律的一次明确例外，已如实记录。

## 7. 界面返工记录（2026-11-12）

第一版做成了两栏 + 三个语言按钮（点哪个直接启动），用户指出不符合规范。返工为规范三栏：

- **中栏下拉框**：按 `leather-recipes.md §4` 用自绘 `SelectPanel` + `ContextMenuStrip`（不用原生 ComboBox，白底在皮革上突兀），默认简体中文（`mode=0`）。
- **ComboHint 硬约束 18**：下拉框上方紧贴一行「本下拉框的作用是：…」，前缀不能省。
- **右栏键帽表**：FPS 常用键位，鼠标操作写普通文字不画键帽（规范：只有真键盘键才画键帽）。
- **平台契约不变**：游戏仍是直接子进程、启动器陪跑、退出码原样回传、关窗不杀游戏。

**踩的坑**：`SelectPanel` 新建后必须调 `PlaceSelector` 定位到 `rcComboMode`，否则控件停在 (0,0)，浮到窗口左上角/标题栏处（PrintWindow 抓图实测发现并修复）。原因：`LayoutRects()` 在 `selLang` 创建之前跑，那次 `PlaceSelector` 拿到 null 直接返回；创建后没补一次定位。
