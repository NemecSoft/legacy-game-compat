# 战神III 重制版（SpartanPort 移植版）适配过程分析

目录：`D:\YunGame\F\GodofWarIIIRemastered`（约 47 GB）
交付日期：2026-11-03

## 1. 这个包是什么

不是官方 PC 版，而是 **SpartanPort 移植版**（上游 `FelipePrado0/SpartanPort`，XDGAME 打包分发）：
用原生 C/C++ 重写 PS4 运行时（`src/runtime_*.c`），直接加载游戏自己的 `game\eboot.bin`（CUSA01740，APP_VER 01.01），
渲染走 **Vulkan**，音频走移植器自己的混音。因此：

- **不需要 DXVK / dgVoodoo / cnc-ddraw**，也没有 `d3d9.dll` 之类翻译层可装；
- 没有 `config.ini`，设置分两个文件：
  - `spartanport.ini`（移植器画面/性能，游戏内 Insert 菜单改的是同一份）
  - `settings.json`（启动器自己的设置：语言、补丁、按键、模组、着色器策略）
- 存档在 `user\`，运行产物在 `out\`（boot bin、补丁、着色器缓存）。

## 2. 原版启动链取证（不是猜的，全部实测）

`开始游戏.exe`、`游戏设置.exe`、`Play God of War III.exe`、`Play SpartanPort.exe` 四个文件**字节大小完全相同**
（247,808 字节，SHA-256 `be177364…77d41`），是同一个 XDGAME `PortableEntry` 壳（PE32+ / x64 / GUI 子系统，
内嵌清单 `XDGAME.SpartanPort.PortableEntry`，asInvoker，只 import `CreateProcessW`/`CreateFileW`）。
差别只在**自身文件名**：

| 入口 | 实际做的事 |
|---|---|
| `游戏设置.exe` | `SpartanPort.exe`（无参数）→ 打开中文启动器界面 |
| `开始游戏.exe` | `SpartanPort.exe --play` → 再派生 `SpartanPort.exe --run` → `bin\spartanport-probe.exe` |
| 启动器里点「开始游戏」 | `SpartanPort.exe --run` → `bin\spartanport-probe.exe` |

真正的游戏进程与其参数（实测抓取）：

```
bin\spartanport-probe.exe <root>\out\boot-linked.bin
  --content-profile <root>\out\content.bin
  --patches        <root>\out\patches.bin
  --app0           <root>\game
  --user           <root>\user
  --timeout 0
```

`--run` 进程带 **23 个 `SPARTAN_*` 环境变量**（用 psutil 读子进程环境块抓到完整清单），
其中关键的一条：

```
SPARTAN_KEY_MAP=square=J,triangle=K,circle=L,cross=Space,l1=Q,r1=E,l2=R,r2=T,l3=None,r3=None,
                rage=F,options=Tab,touchpad_left=None,touchpad_right=Escape,
                up=1,down=3,left=4,right=2,grab=C,dodge=Left Shift,
                weapon_next=None,weapon_prev=None
```
（这一条就是启动器每次传给移植器的完整键位；纯键盘，整套不含任何鼠标键。）

坑：**单独跑 `SpartanPort.exe --run` 会失败**——它默认去 `D:\YunGame\F\CUSA01623` 找 `eboot.bin`，
报 `No eboot.bin in ... (set SPARTAN_GAME_DIR)`。游戏目录是靠 `SPARTAN_GAME_DIR` 传的（值就是相对路径 `game`，
工作目录为包根）。

**只用键盘，不碰鼠标**（用户定案，2026-11-04）：先前做过一套「键鼠方案」（左键轻攻击、按住右键瞄准转视角、
中键防御、侧键投链刃/闪避），用户看过后决定**只要纯键盘**，所以启动器删掉按键方案下拉，
只留这一套键位；上面表里的「移植器默认」列保留，是为了说明哪些项我们真的改了、哪些照默认走。

**纯键盘方案**右手主战簇按手柄位置铺开 ——
□=J 轻攻击、△=K 重攻击、○=L 抓取/确认、✕=空格 跳跃（J K L 三连，和手柄 □△○ 同序）；
左手肩键/扳机沿用移植器默认 Q 防御、E 投链刃、R 瞄准、C 快捷抓取；
**斯巴达之怒给 T**（占 R2 这个位置，用户实测按 T 才释放）；闪避给 **左 Shift**；
滚轮换武器关掉，用 1/2/3/4 直选武器；拍照模式（移植器默认 P）解绑，免得和别的动作撞键。

**README 与实测冲突（2026-11-04 用户实测纠正）**：移植器 `README.md` 第 316 行写
`F = Rage of Sparta (L3 + R3)`，但 `settings.json` 里 `rage_one_input = true`（移植器默认开，
README 自己也说「one input（on by default）leaves Z and X unused」）时，**实测按 F 没反应，按 T（R2）才释放**。
所以：界面和 bat 提示都只写 T，不再宣传 F；`rage=F` 仍按移植器默认留着（我们没改它，
`settings.json.controls.key` 里也不写这一项）。**结论：按键表里凡是只来自 README/默认表、没有实测过的一律标注，
冲突时以实测为准。**

**方向键 = 翻滚不是镜头**（用户实测纠正）：移植器 README 把方向键写成 `Arrows | right stick (camera)`，
但战神III 的右摇杆在游戏里是**朝方向翻滚**，玩家按 ↑ ↓ ← → 看到的是前后左右翻滚；
镜头本身是自动的。闪避键的语义抄移植器自己的说明
（`Dodge evades the way you are moving, or back when standing still`）：朝移动方向闪，站着不动就往后闪。

写入规则（实测得到，不是猜）：

- `settings.json → controls.key` 只存**与移植器默认不同**的项：
  只写 `square/triangle/circle/r2/touchpad_left/dodge/weapon_next/weapon_prev` 八项
  （Q/E/R/F/C/空格 等与移植器默认相同，因此不写、也不覆盖玩家自己在原版「游戏设置」里改过的肩键）；
- `SPARTAN_KEY_MAP` 每次启动**完整**传给移植器（23 个 `SPARTAN_` 变量之一）；
- 动作名与取值词汇（`Space` / `Left Shift` / `Escape` / `Tab` / `None`，以及默认表里的
  `Mouse Left` / `Wheel Up`）逐字照抄移植器自己的表，不发明新名字；
- 反向验证：**直接回读配置文件**（原版「控制」页读写的就是这份 `settings.json`），
  再看原版界面截图佐证（`evidence\roundtrip-ui-controls.png`）。

### 3.1 界面右栏怎么呈现（三列表，一行一条）

玩家在游戏里看到的是 **PlayStation 符号**（□ △ ✕ ○ 和 L1 L2 R1 R2），不是键盘键，
所以右栏做成三列一张表：**手柄按键 | 说明 | 键盘按键**，一行一条，
玩家看到画面上是什么符号，就在表里找同一个符号那一行，右边就是他该按的键。

- 符号按 PlayStation 传统配色**拟物**画：□ 粉、△ 绿、✕ 蓝、○ 红（画成按钮小帽，不是文字）；
- L1 / R1 / L2 / R2 / L3+R3、L1+○、左摇杆、右摇杆、方向键、触摸板、移植器 也画成金色标签小帽；
- 键盘侧全部画成皮革键帽（现在只有键盘一套，不再出现鼠标键 / 滚轮）；
- 一张表 16 行放得下，右栏不出滚动条。

动作含义来源（两处互相印证，不靠猜）：

- 移植器自己的动作表与默认映射（`SpartanPort.exe` 内嵌表 + 启动器「控制」页截图）；
- 战神III 原版（PS3/PS4）操作：□ 轻攻击、△ 重攻击、✕ 跳跃（二段跳）、○ 抓人/QTE、
  L1 防御弹反、R1 指令键、R2/L2 远程与瞄准、十字键切换武器、L3+R3 斯巴达的怒火
  （ZOL 问答《下战神3各种操作是什么》《战神3怎么换武器》等，与移植器表一致的部分才采用）；
- 移植器 README：`With L2 held (R), the mouse aims with the right stick, for the Head of Helios or the Bow of Apollo`、
  `Rage of Sparta on one input (on by default) leaves Z and X unused`、
  `亚洲版游戏部分确认提示使用圆圈键`。

矛盾处（网上有说 L2/R2 是「魔法」，那是战神1/2 的布局）只采信移植器 README + 实测：
本包 L2 = 瞄准、R2 = 射击/投掷；△ 写成「重攻击」不写「魔法」，避免误导。

### 3.2 镜头能不能给鼠标（用户问过，实测答复）

结论：**不能把镜头（右摇杆）绑成鼠标移动**，所以最终按用户要求走纯键盘。证据：

- 移植器绑定框的官方说明（二进制内嵌文案）：
  `Click a box, then press a key, click a mouse button or turn the wheel` ——
  只接受**按键、鼠标键、滚轮**三种输入，鼠标位移不是可绑定项；
- 鼠标当右摇杆只在**按住 L2 时**生效：
  `Aiming with the mouse while L2 is held (Head of Helios, Bow of Apollo)`，
  风格 `Relative` / `Absolute`（`mouse_aim_style`）、灵敏度 `mouse_aim_sensitivity`、
  以及 `Keep the mouse in the game window`（`mouse_lock`）；
- 另一处鼠标用途是 QTE 转摇杆：`stick_prompts` = `keyboard`（用打字方向）/ `mouse`（Adaptive mouse，用鼠标画圈）。

所以「按住 L2 → 鼠标当右摇杆」这条本来就开着，属于游戏自带行为，启动器不改它。
中间版本做过「把 L2 绑到鼠标右键」的键鼠方案，**最终按用户要求删掉，只留纯键盘**：
右摇杆交给方向键——注意战神III 的右摇杆在游戏里是**前后左右翻滚**，
所以界面这一行写「前后左右翻滚」，不写「镜头」（用户实测纠正）。

移植器「控制」页（`evidence\roundtrip-ui-controls.png`）另两条实测事实：

- `向前/后/左/右移动 = W S A D`、`右摇杆向上/下/左/右 = ↑ ↓ ← →`，
  这两组由移植器默认处理，启动器不写、也不覆盖；
- 页面顶部有开关「使用 L1 + 方向键及 L1 + 叉键切换攻击」（默认未勾选）——
  勾上后 L1+方向键 / L1+✕ 变成切换攻击；我们没动它，玩家要改可在原版「游戏设置」里改。

## 4. 实现（重新实现「游戏设置.exe」）

`Games\GodofWarIII\src\Launcher.cs`，C# / .NET Framework 4.x WinForms + 纯 GDI+ 自绘，
**拟物皮革主题**（AGENTS 规则 10），产物 `game_starter.exe` 53 KB（红线 60 KB），零图片、零第三方 DLL，
图标用仓库资源 `assets\ico.ico`。

界面三栏：左＝游戏介绍，中＝启动说明 + 一个下拉 + 四个按钮，右＝键帽操作说明。

- **启动选项**（AGENTS 规则 20 的两项）：`游戏自动检测（推荐）` / `画面异常时（固定桌面分辨率）`
  第二项才写 `spartanport.ini`：`display_mode=borderless`、`render_resolution=native`、
  `fps_limit=60`、`engine_fps=60`、`vsync=1`、`hdr=0`；第一项**一个字节都不改**。
- 按键不再做成选项（用户定案只用键盘）：启动器固定写上面那一套纯键盘键位，右栏就是那张三列表。
- 按钮：`启动游戏` / `修复画面` / `打开运行日志` / `退出`；窗口永不置顶；技术细节只进 `运行日志.txt`。
- 键盘可达：`Tab` 走「启动选项 → 启动 → 修复 → 日志 → 退出」，
  焦点在下拉上时 `↑↓` 直接换项、`Enter` 展开菜单，烫金焦点环 + 外圈暗描边。
- 平台托管契约：`SpartanPort.exe --run` 是 `game_starter.exe` 的**直接子进程**，启动器陪跑到退出、
  原样回传退出码；关窗只隐藏到托盘不杀游戏；`/go` 零交互，`/desktop`、`/fixdisplay` 供平台/脚本调用。
- 改设置前先备份到 `_legacy_compat_backup\GodofWarIII\`（settings.json、spartanport.ini），
  交付包另有 `一键应用.bat` / `一键撤回.bat`。
- `game_starter.bat` 是平级的控制台菜单版，5 个选项（自动检测启动 / 固定桌面分辨率启动 / 修复画面 /
  打开运行日志 / 退出）与 exe 一致，另外把纯键盘键位抄在两行提示里；
  `/go` 走默认组合；居中用 `_tools\nircmd\nircmdc.exe`（文件名与 bat 逐字一致）。

## 6. 双视角自检（AGENTS 规则 23）

开发者视角：

- 每条界面承诺都对应真实行为：`修复画面` 真的只改上面 6 个 ini 键；按键真的写 settings.json 并传
  `SPARTAN_KEY_MAP`（用假游戏回读验证）。
- 来源可靠：默认映射取自移植器「控制」页界面 + 二进制里的默认表；动作名与取值词汇逐字照抄，不发明。
- 不越界：与移植器默认一致的动作（`move_*`、`look_*`、`l1/r1/l2/rage/grab/cross/options/touchpad_right/十字键`）
  不写进 settings.json，避免把玩家自己在原版「游戏设置」里改过的键覆盖成我们的；
  `glyph_style`（游戏内按键图标改成键盘按键）需要启动器另外生成
  约 410 MB 的游戏文件副本，**本启动器没有实现，因此界面上完全不提**，玩家要用就在原版启动器里开。
- 不碰不属于我们的东西：`开始游戏.exe` / `游戏设置.exe` / `user\` 存档 / `game\` 数据一律不动。

玩家视角：

- 启动选项下拉只讲结果，不讲技术：没有 Vulkan、环境变量、ini、JSON 这些词。
- 下一步明确：正常点「启动游戏」；画面不对选第二项或点「修复画面」；报错点「打开运行日志」。
- 右栏覆盖角色动作（移动 / 前后左右翻滚 / 轻攻击 / 重攻击 / 跳跃 / 抓取 / 防御 / 投链刃 / 瞄准 / 射击 / 闪避 /
  斯巴达之怒 / 切换武器）与暂停、移植器菜单两个系统键；
  **每行都是「游戏里的符号 → 动作 → 你按的键」三件套**，不懂 L1/R2 是什么的玩家也能直接对上；
  键帽只给真键盘按键，鼠标与滚轮写成普通文字，不做假键帽。
- 缺什么：没写「首次启动要等着色器编译」的时间预期以外的加载提示；
  武器技能（L1+□/△/✕/○ 组合）与空中冲刺（R3）等进阶操作没列，玩家可在游戏内「操作」页查看。
