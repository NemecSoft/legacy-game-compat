# 虐杀原形 Prototype 适配过程

## 目录与启动链

- 游戏：`D:\YunGame\Prototype\Prototype`，简体中文硬盘版，主程序 `prototypef.exe`。
- 游戏目录原有 `go.bat` 保留不动：`init.exe` → `start /affinity 0x3ff /wait prototypef.exe`。
- 兼容层：目录 `d3d9.dll` 为 DXVK（4,046,862 字节，与 P2 同版本），`_dxvk\` 已留底；
  原 `d3d9.dll.dgvoodoo-bak` 等旧备份保留不动。

## 亲和性（重要）

- 直接启动 `prototypef.exe`（不设亲和性）曾在本机崩在 `prototypeenginef.dll`，事件日志
  `0xc0000005`，偏移 `0x671dbd`。
- 按 `go.bat` 的 `0x3ff` 亲和性启动正常（`start /affinity 0x3ff`）。
- 启动器用 `CreateProcess(CREATE_SUSPENDED)` 建进程，先 `SetProcessAffinityMask(0x3ff)` 再
  `ResumeThread`，游戏是启动器的直接子进程；启动器陪跑并回传游戏退出码。
- 启动器和 go.bat 一样，**不加任何分辨率/窗口参数**，不改游戏设置。

## 为什么用 DXVK 2.3.1，不用 dgVoodoo2

- 本机 dgVoodoo2 的 D3D11 输出有洋红、P2 的 pure3d 引擎还会在 `CreateVertexBuffer` 断言崩溃；
  D3D12 后端直接退出。DXVK 2.3.1 画面干净（详见 `references/cases.md` 第 2 节）。
- AMD 驱动缺 `VK_KHR_load_store_op_none`，DXVK 3.x 报 `No adapters found`，所以锁 2.3.1。
- 旧的 dgVoodoo 备份仍留在游戏目录，不删；交付层是 DXVK。

## 实施阶段 HUD（证明走的是 DXVK，不是显卡原生）

- 用 HUD `version,api,fps` 取证（可临时设 `DXVK_HUD=version,api,fps`，不改游戏配置）：
  左上显示 `DXVK v2.3.1 / D3D9 / FPS 59.9`，不显示显卡型号（`evidence/prototype1-hud.png`）。
- `devinfo` 只显示 RX 580，不能当兼容层证据，已停用；交付 `dxvk.conf` 写
  `dxvk.hud = fps`，左上角只显示帧数；版本/API 只在取证时临时开。

## 启动器

- GUI `game_starter.exe`（900×620 三栏、规范红渐变、正常 TextRenderer ClearType）：
  - 中栏：启动游戏 / 打开运行日志 / 退出；不加分辨率等参数。
  - 右栏：进游戏说明、操作说明（键帽：WASD、鼠标、空格、Shift、E、Esc）、提示；可滚轮。
  - 左栏：游戏介绍 + 玩不了或报错。
  - 启动前按 go.bat 执行 `init.exe`（存在才跑），再以 0x3ff 亲和性启动 `prototypef.exe`。
- 控制台版 `game_starter.bat`：菜单 1 启动 / 2 日志 / 3 退出，`/go` 零交互；与 GUI 选项一致。
- 构建：`Games\Prototype1\build.ps1` → 31.5 KB；构建时从 `prototypef.exe` 抽图标并 `-win32icon` 嵌入，
  文件图标与游戏图标一致。
- `兼容修复.bat` / `恢复原版.bat`：恢复/移除 `_dxvk` 的 DXVK；游戏、汉化未动。

## 验证与证据

- `evidence/prototype1-hud.png`：DXVK HUD（`DXVK v2.3.1 / D3D9 / 59.9 FPS`，无显卡型号）。
- `evidence/prototype1-hud-delivery.png`：历史取证（`DXVK v2.3.1 / D3D9 / 64.2 FPS`）。
- `evidence/prototype1-fps-only.png`：当前交付实机验证，左上角只有 `FPS: 60.8`，
  证明 `dxvk.conf` 的 `dxvk.hud = fps` 已生效。
- `evidence/prototype1-first.png`：按 go.bat 链启动后的加载画面（1280×720）。
- `evidence/prototype1-launcher.png`：启动器界面。
- 分辨率/画质由游戏内「选项」控制；启动器不覆盖、不传参数。
- 启动器实测（2026-11-02）：`/go` 先跑 init.exe（退出码 10），再启动 prototypef；
  游戏父进程 = 启动器 pid，亲和性 0x3FF；关闭游戏后启动器退出码 0，桌面恢复 1920×1080。
