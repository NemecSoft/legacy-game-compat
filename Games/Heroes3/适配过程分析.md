# 英雄无敌3：死亡阴影 Heroes of Might and Magic III 适配过程

## 游戏与目录

- 路径：`D:\YunGame\E\Heroes3`
- 版本：v3.1 简体中文完整版（New World Computing，2000-10-26 构建）
- 主程序：`Heroes3.exe`，导入 `DDRAW.dll`（1999 年 DirectDraw 2D 游戏）
- 现有兼容层：`ddraw.dll` = **cnc-ddraw 7.1**，`ddraw.ini` 已按 GDI 软件渲染配置
- 现有联机：IPXWrapper 0.7.2 + `ipxconfig.exe`（IPX/SPX 转 UDP；游戏也支持 TCP/IP）
- 原有 `go.bat`：设置游戏注册表 `AppPath/CDDrive` 后启动 `Heroes3.exe`；
  **不写 XP 兼容性，也不改显示模式**。启动器不调用 go.bat，保留原文件。

## 兼容层选择（给玩家的四种显示方式）

游戏是 DirectDraw；cnc-ddraw 提供四种交付预设，默认全部是 **GDI 软件渲染**：

| 方式 | 预设 | 用途 |
|---|---|---|
| 稳定全屏（GDI，默认） | `_presets\ddraw.ini` | 自动全屏，最稳；不碰显卡 3D 驱动 |
| 保持 4:3（左右黑边） | `_presets\ddraw-43.ini` | `maintas=true`，避免人物被拉胖 |
| 窗口模式 1280×720 | `_presets\ddraw-window.ini` | 方便 Alt-Tab、HDR/多显示器/覆盖层问题 |
| 原版 640×480（窗口） | `_presets\ddraw-640.ini` | 640×480 窗口，原汁原味 |

**不提供 auto / direct3d9 / DXVK**：本目录的《必读-崩溃修复说明.txt》已记录
`auto → direct3d9 → DXVK` 链路会触发 `dxvk::DxvkError`/黑屏/花屏；GDI 是不碰
显卡 3D 驱动的方式，兼容性最高。不要往本游戏目录放 `d3d9.dll`/`dxgi.dll`。
高刷屏保留 `maxfps=60`，防止 1999 年计时器随刷新率跑飞。

## 启动器

- GUI `game_starter.exe`（37 KB，嵌入 `Heroes3.exe` 图标）：
  - 中栏「启动方式」下拉：四项显示方式；选完直接启动 `Heroes3.exe`。
  - 启动前把对应 `_presets\ddraw*.ini` 复制为游戏目录 `ddraw.ini`；退出后恢复默认预设。
  - 自动检查/设置游戏注册表 `AppPath/CDDrive`（需要管理员时失败只记录，不阻塞启动）。
  - 游戏是启动器的直接子进程；陪跑到退出并原样回传退出码；关窗转后台不杀游戏。
  - 左栏游戏介绍/报错；右栏进游戏说明、鼠标/键盘操作、窗口模式切换、IPX 联机提示。
  - cnc-ddraw 的 `[Heroes3]` 虽配置了 F4 单键切换，但 Win11 下合成按键实测不触发，
    界面不写未验证的快捷键；换窗口统一用启动器的「窗口模式」预设。
- 控制台 `game_starter.bat`：同一套四项显示方式 + 打开日志/退出；`/go` 默认稳定全屏。
- `兼容修复.bat`：恢复 `_cnc-ddraw\ddraw.dll`、补默认预设、设置 AppPath/CDDrive；
  不写 XP 兼容性。`/quiet` 供启动器/应用脚本调用。
- `go.bat` 保留未改；我们的启动器不依赖它。

## 一键应用 / 一键撤回（交付包）

- 位置：`Games\Heroes3\release\`，入口 `一键应用.bat` / `一键撤回.bat` + `payload\`。
- payload：启动器 exe/bat、`launcher.ini`、`兼容修复.bat`、`ddraw.dll`、默认 `ddraw.ini`、
  `_presets\ddraw*.ini`、`_cnc-ddraw\ddraw.dll`/`ddraw.ini`、`_tools\nircmd\ircmdc.exe`。
- 应用：校验 `Heroes3.exe`，备份目标同名文件到 `_legacy_compat_backup\Heroes3\`，
  复制 payload，调用 `兼容修复.bat /quiet` 设置 AppPath/CDDrive；写 `交付记录.txt`。
- 撤回：按 manifest 恢复被替换文件、删除未修改的交付文件，玩家改过的跳过并记录；
  删除 `运行日志.txt`；**不碰 `go.bat`、存档、游戏资源**。注册表 AppPath/CDDrive 不自动恢复，
  已在记录里写明。
- 源脚本：`src\一键应用.bat` / `src\一键撤回.bat`；`build-release.ps1` 组装 payload/manifest。
  测试：`tools\test-delivery.ps1`（假目标应用/撤回、ddraw/预设/记录，全部 PASS）。
