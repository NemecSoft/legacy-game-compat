# X战警前传：金刚狼 启动器适配过程分析

游戏目录：`D:\YunGame\M\X-MenOrigins-Wolverine`（2009 动视、Raven Software，UE3 引擎，简体中文硬盘版）。
交付：`game_starter.exe` + `launcher.ini` + `game_starter.sha256`，全部绿色、只放游戏目录（规则 27 / 36 / 43）。

## 1. 三条用户要求与对应实现

| 要求（2026-11-21） | 实现 |
|---|---|
| 写启动器 | 以 `Games\CC1RedAlert\src\Launcher.cs` 为底本移植：皮革三栏、单按钮启动、平台托管契约、`--readings/--checkfiles/--wer/--selftest/--go/--hideparent` 全套 |
| 分析 reg.fix.exe 并重新动态按所在目录实现 | 动/静态取证出唯一有效键，启动器每次启动**动态写**注册表（见 §2） |
| init.exe 是默认初始化，启动时默认执行 | 启动器拉起游戏前默认执行 init.exe，并把写死用户名路径动态修正（见 §3） |

## 2. reg.fix.exe 取证（静态 + 动态）

- 静态：UPX 壳（UPX0/UPX1）→ `upx -d` 解出 696KB AutoIt v3 编译体（导入 `Software\AutoIt v3\AutoIt`、
  `RegSetValueExW`），脚本二次加密，autoit-ripper 三种解包器（EA05/EA06/JB01）均失败；
- 动态：`reg export` 三区域（HKLM\SOFTWARE\WOW6432Node、HKLM\SOFTWARE、HKCU\Software）运行前后 diff，
  **唯一有效键** = `HKLM\SOFTWARE\WOW6432Node\Activision\Wolverine\EXEString`（REG_SZ）=
  带引号的 `<游戏目录>\Binaries\Wolverine.exe`；其余 4 条差异是系统通知/计划任务噪声。
  摘要见 `evidence\regfix-diff.txt`，Unpacked 本体留 `evidence\regfix-unpacked.exe`。

启动器实现 `EnsureRegistry`：`RegistryView.Registry32`（游戏 32 位）→ `Software\Activision\Wolverine`；
值相同不写（幂等）；写不了只记日志继续（规则 36：不是必需步骤，不弹框、不要求管理员）。
host-sim 的 R1/R2/R3/R4/R5 断言覆盖：写入、日志自证、幂等、旧路径自动纠正。

## 3. init.exe 默认执行

- 静态：WinRAR SFX（PDB `sfxrar.pdb`），配置 `Path=C:\Users\Administrator\Documents\Wolverine\WGame`、
  `Silent=1`、`Overwrite=2`（跳过已存在）；解出内容 = 11 个 Config ini + `SaveData\Player.wgameprofile`。
- 问题：SFX 目标路径**写死 Administrator 用户名**，换机器必错位（规则 18 不按开发机锁死）。
- 实现 `RunInitSilently`：每次启动默认执行 init.exe（60s 上限、不挡玩家）→ `MigrateHardcodedDocs`
  把写死路径下的内容**只补缺**到当前用户「我的文档\Wolverine」，绝不覆盖玩家存档与设置。
  host-sim 的 I1/I2 断言：首次启动执行、每次启动都执行。

## 4. 启动契约

自带 `运行游戏.bat` = `start Binaries\Wolverine.exe`，工作目录 = 游戏根目录，无参数。
启动器 `CreateProcess "<游戏目录>\Binaries\Wolverine.exe"`，CWD = 游戏根目录；直接子进程、陪跑、
退出码原样回传、关窗转托盘不杀游戏、看门狗、WER 崩溃捕获（`Wolverine.exe`）；
对游戏窗口零干预（规则 44）。
