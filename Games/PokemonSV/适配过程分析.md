## 1. 包性质与启动契约（REA + ilspycmd 反编译，证据在 evidence\）

- 不是模拟器：原生重编译移植（KarPur 0.3.8，SDL3 + Vulkan），游戏 4.0.0 + 零之秘宝 DLC。
  真游戏：`runtime\scarlet\karpur.exe`、`runtime\violet\karpur.exe`。
- 自带 `启动游戏.exe`（.NET Framework 4.x，sha256 fa27745f…c98759）反编译
  （`evidence\launcher-decompiled.cs`、`evidence\managed-strings.txt`）确立契约：
  | 项 | 自带版行为 | 我们的复刻 |
  |---|---|---|
  | 主程序 | `<root>\runtime\<edition>\karpur.exe` | 同（两按钮各传版本） |
  | 工作目录 | `<root>\runtime\<edition>` | 同（CreateProcess dir 参数） |
  | 启动方式 | UseShellExecute=false、CreateNoWindow=true、GUI 无参数 | 同（直接子进程） |
  | 语言 | 读 karpur.ini，缺 lang → env TOTK_LANG=zh-Hans；缺 menu_lang → TOTK_MENU_LANG | 同（进程级 env，退出即消失；ini 已有键不补不覆盖） |
  | 目录准备 | Directory.CreateDirectory(profile\save)，TOTK_PROFILE_DIR 可覆盖 | 同 |
  | 文件检查 | CheckFiles：9 文件存在性 | 同（--checkfiles 开关 + 启动前自检） |
  | VerifySelf | RSA 自签名校验 | **不复刻**（他们的签名） |
  | VerifyRuntime | 全量 SHA256 | **不复刻**（太慢，存在性检查足够绿色交付） |
  | 退出行为 | 游戏退出后 GUI 不关窗 | **改**：随游戏退出回传退出码（平台托管契约） |
  | 默认版本 | 紫 | **改**：朱（与按钮顺序一致；ini DefaultEdition / --edition 可改） |
- 9 必需文件：karpur.exe、SDL3.dll、libopus-0.dll、libiconv-2.dll、totk_xlate.exe、
  romfs-index.bin、exefs\main、exefs\main.npdm、romfs\romfs.bin。
- karpur.ini 现状（只读不写）：fullscreen=0、window_size=1280x720、fps_limit=60、
  operation_mode=docked、lang/menu_lang=zh-Hans 等 13 键。游戏内 F1 也写它 → 玩家设置永不覆盖。

## 2. 规则边界判定

- **规则 37（环境读数钉死）**：karpur 是现代 SDL3 程序，不拿刷新率/磁盘几何当除数 →
  不改刷新率、不动显示模式；`--readings` 仍做全套区间断言 + 日志快照（换机器排障用）。
  本机实测：1920×1080@60、DPI 96、DEVMODEW 220 字节结构对、D: 本地硬盘 512 字节/扇区。
- **规则 44（游戏窗口零干预）**：陪跑循环只观察（看门狗 60s 宽限 + 45s 无窗口 →
  WM_CLOSE → 10s → TerminateProcess），不写任何 SetForegroundWindow/ShowWindow。
- **规则 27**：只交付 game_starter.exe，不写 bat。
- **规则 36/43**：纯绿色，全部动作在游戏目录内；env 只进程级；不碰系统。
- 自带 `启动游戏.exe` 保留不删（用户的文件不动）；平台入口用我们的 game_starter.exe。

## 3. 键位来源与界面

- 权威来源：包内 `游戏启动说明.txt`（默认键盘映射；F1 改映射后以实际绑定为准）。
- 主窗口右栏 6 行极简：移动 WASD / 确认 E / 取消 LeftShift / 主菜单 Space /
  地图 MouseLeft / 镜头方向键（鼠标也行）；深色帽=手柄、金色帽=键盘。
- 「详细按键」独立普通窗口（Show() 非模态、Sizable+MaximizeBox）：两列六卡片
  （移动与镜头 / 确认与菜单 / 肩键 / 十字键与系统 / 移植功能键 / 手柄与提示）+
  底部红框「提醒」（ZL=鼠标右键或 Z、ZR=F 或 X）。结构复用战神III CheatSheetForm，
  数据换本作键位；手柄键全部拟物键帽（Keycaps.cs 标准件）。
- 界面零存档文字（用户点名）、零技术串、无保证词；左栏只讲游戏本身 +
  「玩不了或报错 → 打开运行日志 → 发给我们」。
- 无兼容档位 → 无下拉框 → 硬约束 18 的 ComboHint 不适用。
