# 三角洲特种部队：黑鹰坠落 - 军刀部队（DFBHD）适配过程

## 版本与启动链

- 游戏目录：`D:\YunGame\II\DFBHD`，1.5.0.5（含 Team Sabre 资料片），简体中文汉化外挂（WK，基于 1.5.0.5）。
- 启动链：`game_starter.exe` → `汉化外挂.exe` → `dfbhd.dat`（中文版游戏，进程名就是 `dfbhd.dat`）。
  - `DFBHDLC.EXE` 是**局域网客户端**，不是单机主程序；单机必须走汉化外挂。
  - 汉化外挂负责注入 `LG_Data\LG_DF_BHD_TS.dll` 字体扩展，并使用 `localchn.pff` / `ecn1.pff` 中文资源。
  - 本目录这版外挂会**陪跑到游戏退出**（是 `dfbhd.dat` 的父进程），不能按“外挂拉起游戏就退出”处理。

## 图形层

- 原生 D3D8 在本机建不了设备；历史报错为
  `The resolution test has failed. Please make sure that you have the latest drivers...`。
- 方案：**DXVK 2.5.3** 的 `d3d8.dll` + `d3d9.dll`，放游戏目录；`_dxvk\` 留底（两个 DLL + 交付版 `dxvk.conf`）。
- 实测 DXVK 2.5.3 正常，D3D8 → Vulkan；DXVK 日志出现 `Setting display mode: <分辨率>`。

## 实施阶段 HUD（按要求）

- 早期取证配置 `dxvk.conf`：`dxvk.hud = fps,devinfo,api` → 截图左上显示
  `AMD Radeon RX 580 2048SP`、`D3D8`、`FPS ~59.9`；分辨率由 DXVK 日志的

  后续 HUD 统一用 `version,api,fps`。这张旧截图保留作历史记录，新取证应看到 `DXVK v2.5.3 / D3D8 / FPS`。

- **交付关闭**：`src\dxvk.conf`、游戏目录 `dxvk.conf`、`_dxvk\dxvk.conf` 都把 HUD 行注释掉；
  最终交付实测无 HUD：`evidence\dfbhd-game-1600x1200-no-hud.png`。

## 启动器

- `game_starter.exe`（GUI，三栏 900×620）：
  - 中栏：画面/分辨率下拉（5 档）+ 启动游戏 / 打开运行日志 / 退出；
  - 右栏：进游戏说明、操作说明（键盘键帽，鼠标用普通文字）、提示；内容多时滚轮滚动；
    全窗口统一 TextRenderer（GDI ClearType），左/中/右一致；右栏滚动按整行排版、
    只画视口内的行（不做位图/裁剪），长行拆行，避免叠字；
  - 左栏：游戏介绍 + 玩不了或报错。
- 启动逻辑：写 `dfv.cfg` → 启动 `汉化外挂.exe`（`UseShellExecute=false`）→
  按进程名找到 `dfbhd.dat`（过滤启动时间，避免旧进程）→ 等它退出 →
  把**游戏的退出码**回传给平台。
- 平台托管限制：直接子进程是 `汉化外挂.exe`，`dfbhd.dat` 是外挂的子进程；启动器全程陪跑、
  关窗转托盘、退出码取游戏进程。平台若强制要求“游戏是启动器直接子进程”，这是汉化外挂的限制。
- `game_starter.bat`：菜单 1-5 分辨率、6 日志、7 退出，默认 1600×1200；`/go` 零交互。
  bat 用 `start "" 汉化外挂.exe` 后按进程名等 `dfbhd.dat`，回传游戏退出码。
- 日志：`运行日志.txt` 记录分辨率、外挂 pid、游戏 pid、退出码；启动失败时并入
  `dfbhd.dat_d3d9.log` 最后 20 行。

## 实测

- GUI：默认 1600×1200 → 中文主菜单/任务简报 → 关闭游戏 → 启动器退出码 `0`，桌面恢复 1920×1080；
  截图 `evidence\dfbhd-game-1600x1200-no-hud.png`、`evidence\dfbhd-launcher.png`。
- `game_starter.bat /go`：同上，bat 退出码 `0`，桌面恢复。
- 五档分辨率逐一启动并截图（关掉 HUD 后），见上表。
- 汉化：主菜单、任务简报均为中文；`汉化外挂.exe`、`LG_Data`、`localchn.pff/ecn1.pff` 未改动。
- 游戏内按键（BHD 默认，右栏使用）：WASD 移动、鼠标视角/左键开火/右键瞄准、空格跳、
  X 蹲、Z 趴、C 站、R 换弹、1/2/3 换武器、5 手雷、B 望远镜、N 夜视、Q/E 侧身、Tab 战绩、~ 控制台。

## 交付/回滚

- 交付：`game_starter.exe`、`game_starter.bat`、`launcher.ini`、`dxvk.conf`（HUD 关）、
  `兼容修复.bat`、`恢复原版.bat`、`_dxvk\`、`_tools\nircmd\`；游戏目录不留 `.cs`/`.ps1`。
- 回滚：`恢复原版.bat` 删除 `d3d8.dll`/`d3d9.dll`/`dxvk.conf` 和 DXVK 日志；汉化外挂和游戏文件不动。
