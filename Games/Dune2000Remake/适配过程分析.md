# 沙丘2000 重制版（OpenD2K 简体中文整合版）适配过程分析

游戏目录：`D:\YunGame\F\dune2000Remake`（2026-11-22 点名交付）。
用户原话：「不用做绿色兼容，这个已经是现代项目。」——本作没有兼容层、不写系统、不改刷新率。

## 游戏本体与启动契约

- 主程序 `D2kRemake_TrustBox.exe`：x64 GUI，PE 头 `machine=0x8664`、`subsystem=2`，6 MB。
- 自带 `启动游戏.bat` 分两段：先 `_1080p.ps1 -Prepare` 改 `config\settings.ini`
  （dataDir 相对、fullscreen=0、resolution=1920x1080），再 `start` 主程序，最后再跑
  `_1080p.ps1` 等主窗口出现后 `ShowWindow(3)` 最大化。
- 启动器契约：`CreateProcess` 直接拉起主程序、**无参数**、工作目录 = 游戏目录，与 bat 的第一段一致。
  **不复刻 `_1080p.ps1` 的窗口最大化 / SetForegroundWindow**：那是对游戏窗口的干预
  （AGENTS 规则 44，CoD5/CoD8 两轮实测被打回）。启动器也不改 `fullscreen` / `resolution`，
  这些是玩家在游戏内「设置」里的选择。
- `config\settings.ini`：UTF-8 无 BOM、LF 换行，`dataDir=data`（相对）。
  **游戏退出时会把 dataDir 重写成绝对路径**（自带 `_1080p.ps1` 末尾注释明写并实际还原），
  换目录 / 换盘后就找不到数据。启动器在游戏退出后做一次幂等还原
  `RestorePortableDataDir`：只把「绝对路径 == 本目录 data」的值改回 `data`，
  其余行逐字不动、LF 保留、无 BOM 保持；玩家真的把数据放在别的目录（绝对路径不是本目录 data）
  就保留不动，不覆盖玩家设置。
- 文件检查 6 文件 + 3 目录：`D2kRemake_TrustBox.exe`、`SDL3.dll`、`data\DATA.R16`、
  `config\settings.ini`、`lang\zh\Text.uib`、`artpacks\opend2k-redesign\pack.ini`；
  目录 `data`、`lang\zh`、`config\lang\zh`。缺了界面只说一句人话，缺什么进日志。
